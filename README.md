# 프로젝트 회고

### 스프린트 4 회고록

배운 개념을 스프린트에 많이 적용하지 못했습니다.
개념을 통해 적용하는 것이 부족하여 미션을 제시간에 완성 하지 못했습니다.
좀 더 실습을 많이 하면서 다음 미션에는 잘 적용하여 완성하고 싶습니다.

### 스프린트 5 회고록

배운 개념을 이헤 했지만 스프린트에 적용하는 것이 어려워 미션을 완성하지 못했습니다.
개념을 통해 적용하는 것이 부족하여 미션을 제시간에 완성 하지 못했습니다.
초급 프로젝트를 하면서 다음 미션에는 잘 적용하여 미션의 절반을 완성하고 싶습니다.
