# 🐼 판다마켓 프로젝트

## 소개

코드잇 스프린트 미션1,2 과제로 중고거래 서비스 플랫폼입니다. <pr>
기획 단계의 피그마 디자인을 바탕으로 실제 동작하는 화면을 구현하였습니다.

## 주요 기능

- 메인 페이지
- 로그인
- 회원가입

## 기술 스택

- HTML
- CSS

## 회고

**JavaScript 활용**

- **비밀번호 시각화 기능**: 보안을 위한 눈 모양 아이콘(Password Visibility Toggle) 기능을 시간 내에 구현하지 못한 점이 아쉽습니다.

- **입력값 활성화 기능**: input 요소의 활성화 상태(Validation)를 완벽히 제어하지 못했습니다.

- **계획**: 자바스크립트를 더 학습하겠습니다.
