# 판다마켓 로그인/회원가입 페이지 작성 및 랜딩페이지 연결

## 📌 프로젝트 소개

Figma 디자인을 바탕으로 HTML/CSS를 활용해 구현한 로그인 및 회원가입 페이지입니다.

## 🛠 사용 기술

- HTML, CSS

## 🛠 사용 협업툴

- Git, Github

## 🚀 주요 기능

- Flexbox를 활용한 반응형 레이아웃
- form 태그를 활용한 로그인 및 회원가입 정보 입력 폼
- 입력을 위해 해당 플레이스홀더 focus 시 해당 칸 테두리 변경
- 간편 로그인 버튼: 외부 페이지 링크 연결
- 회원가입 버튼: 회원가입 페이지 링크 연결
- 로그인 버튼: 로그인 페이지 링크 연결
