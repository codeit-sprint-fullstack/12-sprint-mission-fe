# 12-Sprint-Mission

## 📌 프로젝트 소개

1-Sprint-Mission은 HTML과 CSS를 활용하여 웹 페이지의 기본 구조와 스타일링을 구현하는 것을 목표로 한 프로젝트입니다.  
웹 표준과 레이아웃 구조에 대한 이해를 높이고, CSS를 활용한 화면 구성 능력을 기르기 위해 제작되었습니다.

---

## 🛠 사용 기술

- HTML
- CSS

---

## ✨ 주요 기능

- HTML을 활용한 웹 페이지 구조 설계
- CSS를 활용한 레이아웃 및 스타일링
