# 스프린트 미션5

## 📌 프로젝트 소개

React 기반의 프론트엔드와 Node.js(Express) & Prisma 기반의 백엔드를 연결한 풀스택 중고거래 플랫폼 재작성

## 🛠 사용 기술

- Frontend: React, React-Router-DOM
- Backend: Node.js, Express
- Database: PostgreSQL
- ORM: Prisma

## 🛠 사용 협업툴

- Git, Github

## 🚀 주요 기능

# 🛒 상품 목록 페이지 (ItemsPage.jsx)

사용자가 등록된 전체 상품을 확인하고 원하는 상품을 빠르게 찾을 수 있는 핵심 페이지입니다.
useEffect와 fetch API를 사용하여 서버의 상품 데이터를 동기화합니다.
검색 기능: 키워드 입력 및 파라미터를 이용하여 상품명 및 상세 설명 내의 특정 단어를 필터링합니다.
정렬 기능: '최신순(recent)', '오래된순(oldest)' 옵션을 제공하여 사용자 맞춤형 리스트를 렌더링합니다.
페이지네이션(Pagination): 한 페이지당 10개의 아이템을 보여주며, 하단 페이지 번호를 통해 데이터를 효율적으로 조회합니다.

# 📝 상품 등록 페이지 (RegistrationPage.jsx)

사용자가 직접 상품 정보를 입력하고 서버 DB에 저장하는 인터페이스를 제공합니다.
사용자가 태그 란에 단어를 입력하고 엔터를 누르면 #태그 형태의 칩이 하단에 추가됩니다.
필수 값 누락 시 alert로 사용자에게 알림을 보냅니다.
값을 입력하고 등록 클릭 시 중고마켓 페이지 내에 상품 추가가 정상적으로 됩니다.

# 📝 상품 상세 및 등록 API (index.js)

Prisma를 활용하여 안정적인 데이터베이스(PostgreSQL) 연동을 구현했습니다.

상품 등록 (POST): name, description, price, tags 데이터를 받아 새로운 상품을 생성
상세 조회 (GET): 상품의 고유 ID를 파라미터로 받아 개별 상품의 모든 정보 로드
상품 목록 조회 (GET): 파라미터를 인식하여 전체 상품 중 필터링된 제품 정보를 나열
상품 수정(PATCH): 현재 화면 중에는 쓰이지 않은 메소드지만 기본 수정 로직 구현
상품 삭제 (DELETE): 현재 화면 중에는 쓰이지 않은 메소드지만 기본 삭제 로직 구현
